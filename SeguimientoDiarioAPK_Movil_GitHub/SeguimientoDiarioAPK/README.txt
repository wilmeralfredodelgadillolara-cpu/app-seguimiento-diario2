Seguimiento Diario - Proyecto Android APK

Pasos:
1. Instala Android Studio en tu PC.
2. Abre esta carpeta: SeguimientoDiarioAPK.
3. Espera la sincronización de Gradle.
4. En Android Studio: Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK generado: app/build/outputs/apk/debug/app-debug.apk

La app funciona sin internet y guarda datos localmente en el teléfono.
